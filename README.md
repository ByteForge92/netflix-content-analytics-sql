# 🎬 Netflix Content Analytics using SQL

## 📌 Project Overview
Performed end-to-end data analysis on Netflix's content dataset using SQL to extract insights related to content distribution, growth trends, genres, and contributor patterns.

This project demonstrates how raw data can be transformed into actionable insights using SQL techniques such as aggregations, CTEs, and window functions.

---

## 🎯 Objectives

- Analyze the distribution of Movies and TV Shows  
- Identify trends in content addition over time  
- Evaluate genre popularity and content categories  
- Study contributions by countries, actors, and directors  
- Perform content classification based on textual data  

---

## 🛠️ Tools & Technologies

- **SQL (MySQL)**
- **Excel / CSV Dataset**
- Concepts Used:
  - Aggregations (`COUNT`, `AVG`)
  - String functions (`SUBSTRING_INDEX`, `STR_TO_DATE`)
  - **CTEs (Common Table Expressions)**
  - **Window Functions (RANK)**
  - Data Cleaning & Transformation  

---

## 📊 Key Analysis Areas

- 📊 Content Distribution & Core Analysis  
- 📈 Time-Based Trends & Growth Analysis  
- 🎬 Genre & Content Insights  
- 🌍 Country & Actor Analysis  
- 🎥 Content Exploration & Data Quality  
- 🧠 Advanced Analysis & Classification
